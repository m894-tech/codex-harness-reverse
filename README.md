# Codex (ChatGPT.app) — разбор харнеса

Спецификация агентского харнеса Codex, восстановленная из **скомпилированного бинаря** и конфигурации
на диске. Дополняет разбор Hermes Agent: это независимый дизайн, а не его вариант.

Объект: `/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex`
(Rust, Mach-O arm64, 285 MB). ChatGPT.app `26.1117.31558`, Codex CLI `0.147.0`.

Метод: `strings -n 60` (53 056 строк), промпты лежат JSON-шаблонами в коде; конфиг, агенты, хуки,
правила — с диска (`~/.codex/`).

## Что здесь главное

1. **Авторизация важнее подтверждения.** Разрешение живёт между ходами; подтверждение — только на
   необратимое и только после того, как работа доведена до «можно ревьюить».
2. **Три режима sandbox** с валидацией несовместимых комбинаций на старте.
3. **Auto-review — LLM-классификатор** (`high`/`low`) вместо человека на каждом шаге.
4. **Субагенты — треды** с каноническими именами, а не функции: спавн только по явному запросу.
5. **Хуки** — детерминированные точки (`PreCompact`, `SessionStart`, `PreToolUse`, `Stop`…).

## Границы

Промпты извлечены из строк бинаря: возможны артефакты склейки в длинных литералах. Всё остальное —
чтение конфигурации. Рантайм-замеров нет, статусы в `EVIDENCE.md`.
